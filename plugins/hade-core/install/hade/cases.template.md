# 个人记忆层 · 反例库（空模板）

> 由 `~/.claude/CLAUDE.md` 通过 `@hade/cases.md` 在启动时展开进上下文。
> **实测：import 是确定性加载，不是按需读取** —— 写在这里的内容一定会进上下文，
> 不像 skill 那样依赖概率触发。

## 这个文件是干什么的

骨架里的规则只讲"该怎么做"，这里存"我在哪里错过"。

实测证据：把一条具体的失败记录写进规则，手算准确率从 0/3 提升到 3/3 ——
起作用的不是新知识，而是"你上次在这里翻过车"这个具体事件。
所以这个文件越具体越有用，写成"要注意数据安全"这种空话等于没写。

## 怎么用

**开始是空的，这是正常的。** 每次你纠正 AI、或它自己发现犯了错，
让它按下面格式追加一条。几周后这里会长出你自己的教训库。

```markdown
### M-01 · 对应章节

具体发生了什么 → 导致什么后果 → 正确做法是什么。
带上真实的数字、文件名、你的原话 —— 越具体唤醒力越强。
```

然后在骨架对应规则下加一行 `反例：见记忆层 M-01`。

## 清空

直接删掉本文件下方所有 `### M-xx` 条目即可。
骨架规则不受影响，只是失去"我在这里错过"这层提醒。
