# HADE 系列命名系统

> 所有 HADE 家族工具的代号规则。
> 给新项目/工具取代号时读此文件。

---

## 命名哲学

HADE 世界的内部代号系统 — 每个工具在家族里有一个**希腊词根**的代号，形成一致性。

- **代号** = 内部文件夹名、HADE 世界的家族坐标
- **上架名** = 对外商业名（可加功能副标题，如 `Hora — Daily Task Butler`）
- 希腊词根不够时兜底用拉丁词（同属古典语系，气质一致）

## 选词四原则

1. **贴合核心** — 选最代表产品本质的希腊词（Hora 因为产品核心是日期/时间）
2. **发音优雅** — 2-3 音节最佳，避免辅音堆积（Mnemosyne 就太长）
3. **拼写独特** — 商标友好，没被太多人用过
4. **直译度** — 一 Google 就能查到意思，不要太生僻

---

## 兜底策略

- **希腊词找不到合适的** → 用**拉丁词**作为同家族扩展（Lumen、Nexus、Forum、Verso、Stella、Aurora）
  - 希腊和拉丁同属古典语系，气质一致，不破坏家族感
- **还是不够** → 用**希腊词根造词**（像 Telegraph 由 tele + graph 组成）
- **千万不要** → 中英混合、拼音、随手造字 — 会破坏整套系统的贵族感

## HADE 使用流程

用户准备开新项目时，HADE：

1. 问清楚产品核心功能 / 本质
2. 从【词库分类表】对应功能域挑候选
3. 按【选词四原则】筛选
4. 给用户 1-2 个推荐 + 理由
5. 确定后 **更新本文件的【工具映射表】**
